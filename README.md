# my-site

HTML / CSS / JavaScript だけで作った静的サイト。ビルドは不要。

公開 URL：https://ranran-git.github.io/my-site/

| ファイル | 内容 |
|---|---|
| `index.html` | ページ本体 |
| `style.css` | 見た目（ダークモード、スマホ対応を含む） |
| `script.js` | テーマ切り替え、カウンター、フッターの年表示 |

## ローカルで確認する
`index.html` をブラウザで開く。

## GitHub Pages の設定
1. リポジトリの **Settings → Pages** を開く。
2. **Build and deployment** の Source を **Deploy from a branch** にする。
3. Branch を `main`、フォルダを `/(root)` にして **Save** を押す。
4. 数分後、上記の公開 URL で表示される。以降は `main` に push するたびに自動で反映される。
